# Selenium Hybrid Automation Framework — GUI Elements

A hybrid test automation framework built with **Selenium WebDriver + TestNG + Maven + Page Object Model** for automating GUI elements on [testautomationpractice.blogspot.com](https://testautomationpractice.blogspot.com).

## Features
- Page Object Model (POM) with PageFactory
- Data-Driven Testing using Apache POI (Excel)
- Cross-Browser Testing — Chrome & Edge
- Parallel Execution using TestNG
- Extent Reports with screenshot on failure
- Log4j2 logging to console and file
- Jenkins CI/CD pipeline ready

## Tech Stack
Java • Selenium WebDriver 4.18.1 • TestNG • Maven • Extent Reports • Log4j2 • Apache POI • WebDriverManager

## Test Coverage
Text Fields • Radio Buttons • Checkboxes • Dropdowns • Date Picker • Simple/Confirmation/Prompt Alerts • Mouse Hover • Double Click • Drag and Drop • Slider

## Results
24 tests — 12 Chrome + 12 Edge running in parallel | 0 failures
